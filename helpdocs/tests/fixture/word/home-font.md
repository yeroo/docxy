# Font group

Make text **bold** with <kbd>Ctrl+B</kbd>, *italic* with <kbd>Ctrl+I</kbd>.

## Effects

1. Select the text.
2. Open the Font dialog with <kbd>Ctrl+D</kbd>.
3. Tick Strikethrough.
