# Home tab

The Home tab holds the commands you use most:

- Clipboard: cut, copy and paste
- Font: see [Font](home-font)
  - the font name and size boxes
- Paragraph

## Clipboard

Press <kbd>Ctrl+C</kbd> to copy and <kbd>Ctrl+V</kbd> to paste.

In the Styles box, type a style name such as `Heading 1`.
