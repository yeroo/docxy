# Round-trip fidelity allowlist (#1060): deliberate, benign normalizations the
# gate tolerates. One rule per line:
#
#   kind | part glob | index-free path glob | reason
#
# `*` matches any run of characters, including `/`. The reason is mandatory.
# Shrinking this file is progress; growing it needs review. Losses that are
# real but not fixed yet belong in baseline.txt, not here.

extra-attr | word/document.xml | */w:t/@xml:space | The serializer writes xml:space="preserve" on every w:t. It changes nothing for text without leading or trailing whitespace and keeps such whitespace when there is some.
extra-attr | word/document.xml | */@mc:Ignorable | Preserved raw subtrees (tables, drawings) get the effective mc:Ignorable of their ancestors redeclared, so the ignorable prefixes they use stay declared. The tokens repeat the root's.
part-extra | word/styles.xml | * | save_package adds a styles part defining the table styles the body references when the package has none (add_referenced_table_styles).
extra-element | [Content_Types].xml | /Types/Override | The content-type override for that added styles part.
