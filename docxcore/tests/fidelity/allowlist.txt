# Round-trip fidelity allowlist (#1060): deliberate, benign normalizations the
# gate tolerates. One rule per line:
#
#   kind | part glob | index-free path glob | detail glob | reason
#   kind | part glob | index-free path glob | detail glob | once-with <kind> <part> | reason
#
# `*` matches any run of characters, including `/`. The detail is what the
# report prints after the path:
#   lost-attr, extra-attr          the attribute's decoded value, unquoted
#   changed-value                  "old" -> "new", each Rust-Debug-quoted
#   lost-/extra-element, text()    the text, Rust-Debug-quoted
#   lost-/extra-element, element   its attributes as name="value" pairs, sorted
#                                  by namespace URI and local name, values
#                                  Rust-Debug-quoted (so `"` and `\` are escaped)
#   part-bytes, load-error, panic  free text; part-missing, part-extra: empty
# `once-with <kind> <part>` limits a rule to files that also have a finding of
# that kind in that part, and to one finding per file.
#
# The reason is mandatory. Shrinking this file is progress; growing it needs
# review. Losses that are real but not fixed yet belong in baseline.txt, not
# here.

extra-attr | word/document.xml | */w:t/@xml:space | preserve | The serializer writes xml:space="preserve" on every w:t. It changes nothing for text without leading or trailing whitespace and keeps such whitespace when there is some.
extra-attr | word/document.xml | */@mc:Ignorable | * | Preserved raw subtrees (tables, drawings) get the effective mc:Ignorable of their ancestors redeclared, so the ignorable prefixes they use stay declared. The tokens repeat the root's.
part-extra | word/styles.xml | * | * | save_package adds a styles part defining the table styles the body references when the package has none (add_referenced_table_styles).
extra-element | [Content_Types].xml | /Types/Override | ContentType="application/vnd.openxmlformats-officedocument.wordprocessingml.styles+xml" PartName="/word/styles.xml" | once-with part-extra word/styles.xml | The content-type override for that added styles part: only in a file where the part was added, and only once.
extra-element | word/document.xml | */w:tbl/w:tblGrid |  | CT_Tbl requires tblGrid, so the serializer writes one for a table that had none (#1083). The schema check rejects a second one.
